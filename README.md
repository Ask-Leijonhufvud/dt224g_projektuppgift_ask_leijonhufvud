[GitHub Pages]

## Uppgiftsbeskrivning

Detta är en projektuppgift som gick ut på att man skulle skapa en webbplats för en valfri verksamhet, antingen verklig eller fiktiv. Projektet ska inte utformas som en personlig blogg eller portfolio.

Projektets syfte var att:
> * planera, designa och utveckla en komplett webbplats för en vald verksamhet, med en tydlig målgrupp och ett kommunikativt syfte,
> * skapa en genomtänkt grafisk profil och responsiv design anpassad efter verksamheten och dess målgrupp,
> * använda HTML, CSS och JavaScript för att skapa en strukturerad, tillgänglig och interaktiv webbplats,
> * använda Git och GitHub för att versionshantera projektet och visa en kontinuerlig utvecklingsprocess,
> * publicera den färdiag webbplatsen på en publik webbaddress,
> * dokumentera, presentera och motivera de val och lösningar som gjorts under projektets utveckling.
