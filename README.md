## Uppgiftsbeskrivning

Detta är en projektuppgift som gick ut på att man skulle skapa en webbplats för en valfri verksamhet, antingen verklig eller fiktiv. Projektet ska inte utformas som en personlig blogg eller portfolio.

Projektets syfte var att:
> * planera, designa och utveckla en komplett webbplats för en vald verksamhet, med en tydlig målgrupp och ett kommunikativt syfte,
> * skapa en genomtänkt grafisk profil och responsiv design anpassad efter verksamheten och dess målgrupp,
> * använda HTML, CSS och JavaScript för att skapa en strukturerad, tillgänglig och interaktiv webbplats,
> * använda Git och GitHub för att versionshantera projektet och visa en kontinuerlig utvecklingsprocess,
> * publicera den färdiag webbplatsen på en publik webbaddress,
> * dokumentera, presentera och motivera de val och lösningar som gjorts under projektets utveckling.

## Filer

Detta är en lista över de filer som ingår i projektet och vad de innehåller.

* about.html: html för sidan About Us
* contact.html: html för kontaktsidan
* index.html: html för huvudsidan
* README.md: denna README

### assets

Denna mapp innehållar alla bildfiler som jag använt för webbplatsen.

* logo.png: verksamhetens logga

### css

Denna mapp innehåller alla css filer som används i projektet.

* about.css: de css regler som är unika för sidan About Us
* base.css: de css regler som är gemensamma för alla sidor på webbplatsen
* contact.css: de css regler som är unika för kontaktsidan
* index.css: de css regler som är unika för huvudsidan

### js

Denna mapp innehåller alla JavaScript-filer som används i projektet.

* base.js: den JS kod som är gemensam för alla sidor på webbplatsen.
* contact.js: den JS kod som är unik för kontaktsidan.

### Wireframes och Mockup

Denna mapp innehåller de wireframes och den mockup som jag skapade i början av projektet. De är sparade i både .xcf och .jpg format. (.xcf är det filformat som används av bildbehandligsprogrammet GIMP, som är det som jag använt för att skapa WFs och mockup)
